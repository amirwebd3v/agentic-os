# W2-03: Redaction and placeholders

**Points:** 2 · **Wave:** 2 · **Risk:** Med · **Depends on:** none
**Read first:** contract §1, §3.2, §3.3, §10 (W2-03). Plan: [[implementation-plan]]. Skills by step: [[skills-map]].

## Summary
Contact details (name, email, phone, address, URL, date of birth) never appear in a prompt. A model sees placeholders; the values are put back only at render time (W2-09).

## Steps
1. **Recall.** `/claude-mem:mem-search <ticket topic>`; before opening a long file, `/claude-mem:smart-explore` it. Keep claude-mem **off** in any session that opens a real CV, contact file, posting or the vault (see [[Workflow]]).
2. `server/src/career/contact.ts`: a `Contact` type and `loadContact(vaultDir)` that reads `career/contact.md` frontmatter with `gray-matter` (already a dependency). A missing file gives `{}`.
3. `server/src/career/redact.ts`: `redactContact(text, contact)` replaces each non-empty value with its `{{CONTACT_*}}` placeholder. Variants: e-mail case-insensitive; phone ignoring spaces, dashes, dots, brackets and a leading `+` or `00`; address line by line; URL with or without scheme and trailing slash; name only as the full name or `Last, First` / `First Last` order (never a lone given name: too many false hits). Values shorter than 3 characters are skipped. `restoreContact` is the inverse; an unknown placeholder is left as is (the verifier flags it, contract §6).
4. One exported `promptSafe(contact, text)` that **every** prompt-building function calls last. No other code path may build prompt text for a model.
5. A test helper `capturePrompts()` returning a fake `llm` that records the `system` and `input` of every call. Inject `llm` as a dependency whose default is `structured`, as the removed `categorizeSession` did (`git show fe1b1dd:server/src/jobs/categorize-session.ts`).
6. Tests per contract §10: each variant, the round trip, overlapping values (a name inside an address), short values skipped.
7. **Check.** `pnpm verify` (judge by exit code) → `/simplify` → `/ponytail:ponytail-review` on the diff → `/code-review medium`, and **`/security-review`** (this is the privacy boundary of the whole slice).
8. **Close.** Tick the acceptance list; `save_memory` (cause → fix for any mistake) and a `CLAUDE.md` Lesson in the same PR if one happened; `/claude-mem:babysit` the PR; `/claude-mem:handoff` if you pause. After reporting ready, push nothing (rule 8).

## Owns (files)
- `server/src/career/contact.ts`, `server/src/career/redact.ts` and their tests

## Acceptance
- [x] A fake-`llm` test proves no contact value, in any variant above, reaches `system` or `input`.
- [x] Round trip: `restoreContact(redactContact(x)) === x` for text that contains the values.
- [x] Nothing is logged: no contact value in a thrown error message.

## Not in this ticket
