# W2-10: Evals and UAT

**Points:** 2 · **Wave:** 5 · **Risk:** Med · **Depends on:** W2-07
**Read first:** contract §10 (W2-10); plan §3, §4 acceptance, §7 R2. Plan: [[implementation-plan]]. Skills by step: [[skills-map]].

## Summary
Measure the pipeline on a fixed set so a prompt or model change can be judged, and decide with data whether the draft step needs the larger model.

## Steps
1. **Recall.** `/claude-mem:mem-search <ticket topic>`; before opening a long file, `/claude-mem:smart-explore` it. Keep claude-mem **off** in any session that opens a real CV, contact file, posting or the vault (see [[Workflow]]).
2. `/claude-api build-eval`: run its interview (what is evaluated, where the inputs come from, how to grade, what it costs) and get your sign-off on inputs, grading and cost before producing the eval.
3. Golden set: synthetic postings and masters committed in `server/test/fixtures/career/` (kept apart from the W2-05 canaries). Grading: the verifier's report (0 unsupported claims), coverage of must-haves, line count and length, plus your 3-way rating (usable / needs edits / wrong) on real runs.
4. `scripts/eval-career.ts`: reuse `eval_cases` / `eval_runs` with a `career-tailor` suite (inputs and results are free JSON; the old categorize script is in `git show fe1b1dd:scripts/eval-categorize.ts`). Run it against the real provider.
5. Baseline run with Sonnet 5.5 at `high`. If unsupported claims > 0 after the retry, or more than 20% of your ratings are "needs edits" or worse, run `/claude-api hillclimb` on the draft prompt (train/validation split), then the `deep` comparison of plan R2.
6. **UAT** (with the owner, claude-mem off): 3 real postings from outside the repo, end to end, then rate the first 5 drafts.
7. **Check.** `pnpm verify` (judge by exit code) → `/simplify` → `/ponytail:ponytail-review` on the diff → `/code-review medium`.
8. **Close.** Tick the acceptance list; `save_memory` (cause → fix for any mistake) and a `CLAUDE.md` Lesson in the same PR if one happened; `/claude-mem:babysit` the PR; `/claude-mem:handoff` if you pause. After reporting ready, push nothing (rule 8).

## Owns (files)
- `scripts/eval-career.ts`, `server/test/fixtures/career/golden/`

## Acceptance
- [ ] 0 unsupported claims across the golden set; the numbers (coverage, pass rate, cost per application) are written into the PR.
- [ ] The model decision (stay on Sonnet or escalate) is recorded in the plan with the measured reason.
