# W2-06: Job status and the applications API

**Points:** 2 · **Wave:** 2 · **Risk:** Med · **Depends on:** none
**Read first:** contract §4 (attempts), §5, §8.2, §8.3, §9, §10 (W2-06). Plan: [[implementation-plan]]. Skills by step: [[skills-map]].

## Summary
Start a tailoring run with one request and watch its status. A failing step says so within seconds instead of retrying silently for an hour.

## Steps
1. **Recall.** `/claude-mem:mem-search <ticket topic>`; before opening a long file, `/claude-mem:smart-explore` it. Keep claude-mem **off** in any session that opens a real CV, contact file, posting or the vault (see [[Workflow]]).
2. `db/jobs.ts`: a per-kind attempts cap, so `career_*` jobs fail after the first attempt (the global `MAX_ATTEMPTS = 5` stays for everything else). When a career job ends `failed`, mark its application `failed` with `fail_code: 'internal'`: add an `onFailed` callback to `startRunner` and wire it in `main.ts`.
3. `routes/career.ts`: `POST /api/career/applications` (validate: master exists, provider configured, posting ≤ 30,000 characters; store the posting in `application_texts`; save `master_hash`; enqueue `career_intake`; `202`), `GET` list and detail. Body validation with the Fastify JSON schema and `additionalProperties:false`, as `approvals.ts` does. Errors are the fixed codes of §8.3. Audit with ids and counts only.
4. `web/src/stores/career.ts`: polling every 1.5 s while `status` is `processing` or `step` is `render`; stop on any other state; surface `failed` with its `fail_code` in words.
5. Tests: attempts cap, the failed sweep, validation, `jobs.error` holds no posting text, and a due `other` job starts before the run's next step.
6. **Check.** `pnpm verify` (judge by exit code) → `/simplify` → `/ponytail:ponytail-review` on the diff → `/code-review medium`.
7. **Close.** Tick the acceptance list; `save_memory` (cause → fix for any mistake) and a `CLAUDE.md` Lesson in the same PR if one happened; `/claude-mem:babysit` the PR; `/claude-mem:handoff` if you pause. After reporting ready, push nothing (rule 8).
