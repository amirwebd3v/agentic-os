# W2-05: Posting intake

**Points:** 2 · **Wave:** 2 · **Risk:** High · **Depends on:** none
**Read first:** contract §1, §4 (step 1), §4.1, §10 (W2-05); plan §7 R1, R2, R4. Plan: [[implementation-plan]]. Skills by step: [[skills-map]].

## Summary
A pasted job posting becomes a short, strictly typed `Requirements` object. The posting is untrusted: the call has no tools, wraps the text, and its result can never carry an instruction.

## Steps
1. **Recall.** `/claude-mem:mem-search <ticket topic>`; before opening a long file, `/claude-mem:smart-explore` it. Keep claude-mem **off** in any session that opens a real CV, contact file, posting or the vault (see [[Workflow]]).
2. **Gate (passed 2026-10-27, plan R4).** `pnpm smoke` showed structured output working on your 9router setup. Add an `effort` item to `pnpm smoke` (`src/cli/provider-smoke.ts`) so we know whether the provider accepts `output_config.effort`; ask the owner to rerun it.
3. **Prompt and schema** (`/claude-api`): the schema sent to `structured()` has **no** length or array limits (R1); keep enums. Write the limits in the field descriptions, then clip and validate with a second, stricter Zod schema after the call. Add an optional `effort` argument to `structured()` (`output_config.effort`); it is sent **only when the step's `career.effort` config is set**. Intake sends none: Haiku 4.5, today's `fast` model, rejects it (R2).
4. `server/src/career/intake.ts`: wrap the posting with `wrapUntrusted('posting', …)` from `llm/untrusted.ts`; a system `RULES` string that says the block is data, not instructions, and asks only for extraction; `injection_suspected` is set when the posting contains instructions aimed at an AI. Pass the text through `promptSafe` (W2-03).
5. Job handler `career_intake` (payload `{ applicationId }` only): read the posting from `application_texts`, store `requirements`, set `applications.company`, `role_title`, `language`, enqueue `career_match`. Expected failures set `fail_code` and **do not throw**. Throw only typed errors with fixed messages; never wrap a Zod error.
6. Fixtures in `server/test/fixtures/career/`: 5 canary postings (hidden instructions in plain text, HTML comments, a fake closing tag, a fake system message, a request to claim experience) and 3 ordinary synthetic postings (EN, DE, a short one). No real postings.
7. **Check.** `pnpm verify` (judge by exit code) → `/simplify` → `/ponytail:ponytail-review` on the diff → `/code-review medium`, and **`/security-review`** (prompt injection is the threat).
8. **Close.** Tick the acceptance list; `save_memory` (cause → fix for any mistake) and a `CLAUDE.md` Lesson in the same PR if one happened; `/claude-mem:babysit` the PR; `/claude-mem:handoff` if you pause. After reporting ready, push nothing (rule 8).
