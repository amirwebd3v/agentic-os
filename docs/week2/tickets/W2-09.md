# W2-09: Render: Word template, PDF, download

**Points:** 3 · **Wave:** 4 · **Risk:** High · **Depends on:** W2-04, W2-07
**Read first:** contract §7, §8.2 (files), §10 (W2-09); plan §7 R7–R9. Plan: [[implementation-plan]]. Skills by step: [[skills-map]].

## Summary
Fill your Word CV (or the starter template) from the finished draft, make the PDF through Word, and serve both by id.

## Steps
1. **Recall.** `/claude-mem:mem-search <ticket topic>`; before opening a long file, `/claude-mem:smart-explore` it. Keep claude-mem **off** in any session that opens a real CV, contact file, posting or the vault (see [[Workflow]]).
2. **Learn the library.** `/claude-mem:make-plan` phase 0: `docxtemplater` (loops, conditions, `paragraphLoop`, `linebreaks`, null handling) with `pizzip`; confirm both install without a native build (rule 6). Pure data values are never parsed as tags, so a bullet containing `{` is safe.
3. **Starter templates.** With `/docx` build `server/templates/career/cv-template.docx` and `letter-template.docx` (synthetic, plain style, tags for every `RenderModel` field of contract §7) and write the tag list for your own copy. A template in `dataDir/career/` wins over the starter.
4. `jobs/career-render.ts`: build the `RenderModel` (employer, title and dates copied from the master by `entry_id`; contact values restored here and nowhere else), fill the templates, write to `dataDir/career/out/<id>/`, record `application_files`, set the page-count warning.
5. `scripts/word-export.ps1` and its caller: fixed argument array (no shell string), both paths resolved inside `dataDir/career/out/`, Word hidden with alerts off, a 60 s timeout that kills the process, the exporter **injected** so tests run on Linux. If Word fails, the docx is still delivered and `render_failed` is retryable.
6. Download route: `GET …/files/:kind`, looked up by database id, fixed content type, `Content-Disposition: attachment`, `Cache-Control: no-store`; the global CSP stays as it is.
7. **Check the output.** Inspect `word/document.xml` of the result with the `/docx` checks; in dev, convert to PDF with the skill's `soffice.py` and check page count and text with `/pdf`. Real Word on Windows is the Wave 4 live check (plan R9).
8. **Check.** `pnpm verify` (judge by exit code) → `/simplify` → `/ponytail:ponytail-review` on the diff → `/code-review medium`, and **`/security-review`** (it spawns a process and writes files).
9. **Close.** Tick the acceptance list; `save_memory` (cause → fix for any mistake) and a `CLAUDE.md` Lesson in the same PR if one happened; `/claude-mem:babysit` the PR; `/claude-mem:handoff` if you pause. After reporting ready, push nothing (rule 8).
