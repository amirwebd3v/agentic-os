# W2-08: Application page and the new look

**Points:** 6 · **Wave:** 4 · **Risk:** High · **Depends on:** W2-07
**Read first:** `web/PRODUCT.md`, `web/DESIGN.md` (seed), contract §6, §8.2, [[skills-map]] section C. Plan: [[implementation-plan]]. Skills by step: [[skills-map]].

## Summary
The page where you read a draft line by line, see the bullet behind each line, edit it, and finalise. The same ticket gives the whole app its new look ("The Quiet Ledger") and replaces the seed `DESIGN.md` with real tokens.

## Steps
1. **Recall.** `/claude-mem:mem-search <ticket topic>`; before opening a long file, `/claude-mem:smart-explore` it. Keep claude-mem **off** in any session that opens a real CV, contact file, posting or the vault (see [[Workflow]]).
2. **Shape.** `/impeccable shape` the page (Operate: the task, the information, the states, how often, the constraints) inside the pinned direction (plan R16). No direction round unless you ask for it.
3. **Learn the tokens.** `/claude-mem:make-plan` phase 0: list `@primer/primitives` `dist/css`, pick the light and dark theme files, build, and measure (R13: under 30 kB gzipped, else copy the ~20 values). Reka UI only if a dialog, menu or tabs are truly needed (R14).
4. **Taste pass, once.** `/design-taste-frontend` before building. `DESIGN.md` wins on conflict.
5. **Build.** Shell nav (Applications, Review) and restyle of the Review page and `ApprovalCard`; `ApplicationView.vue`: a reading column and, on wide screens, a source panel showing the master bullet for the line in focus; diff against the master with `diff.ts`; edit in place through `PATCH …/draft`; `flagged` acknowledgement; download links; status polling from `stores/career.ts`; Markdown only through `renderMarkdown`. `style.css` becomes tokens.
6. **Look at it.** `/run` the app; `built-in-browser` screenshots at 1280 and 800 px, light and dark; keyboard-only pass; every state (processing, draft_ready, flagged, failed, final, render failed, empty).
7. **Critique and finish.** `/impeccable critique` → fix → `polish` → `harden` (long titles, German text lengths, many lines) → `audit` → `impeccable detect --json` on the changed files; then `/claude-mem:design-is` as a second lens; fix only material findings.
8. **Document.** `/impeccable document` (scan mode) replaces the seed `web/DESIGN.md` and writes `.impeccable/design.json`.
9. **Check.** `pnpm verify` (judge by exit code) → `/simplify` → `/ponytail:ponytail-review` on the diff → `/code-review medium`.
10. **Close.** Tick the acceptance list; `save_memory` (cause → fix for any mistake) and a `CLAUDE.md` Lesson in the same PR if one happened; `/claude-mem:babysit` the PR; `/claude-mem:handoff` if you pause. After reporting ready, push nothing (rule 8).
